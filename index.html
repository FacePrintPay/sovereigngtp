Common Issues & Troubleshooting

Vercel Deployment Failures (401/404 Errors)
Authentication token expired or misconfigured. Run vercel login to refresh credentials.
  • rm -rf ~/.vercel
  • vercel login
  • vercel link
Termux Storage Exhaustion
Android devices have limited internal storage. Implement aggressive cleanup strategies.
  • bash storage_cleanup.sh --aggressive
  • termux-setup-storage && mv ~/projects /sdcard/
  • npm cache clean --force && pip cache purge
Git Authentication Failures
SSH keys not properly configured or GitHub personal access tokens expired.
  • ssh -T git@github.com
  • eval "$(ssh-agent -s)" && ssh-add ~/.ssh/id_ed25519
  • git remote set-url origin git@github.com:user/repo.git
Agent System Crashes & Instability
Planetary agent systems consuming excessive resources or encountering race conditions.
  • ps aux | grep python
  • pkill -f constellation && ./start_agents.sh
  • tail -f ~/logs/agent_*.log
